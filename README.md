# Games 9999

Landing page for a set of small pocket-LCD browser games. Each card shows an animated dot-matrix preview and links to the game.

- [Pocket Snake](https://npsquared.github.io/PocketSnake/)
- [Brick Game 9999](https://npsquared.github.io/BrickGame9999/)
- [Noomi's Tic Tac Toe](https://npsquared.github.io/XsOs/)
- [Dot Rally](https://npsquared.github.io/DotRally/)

Single file: `index.html`, no build step. Hosted with GitHub Pages from `main`, root folder.
